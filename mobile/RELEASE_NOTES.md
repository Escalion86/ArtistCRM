# ArtistCRM Mobile — Release Notes

## v0.1.0 (Internal Testing)

### Что нового
- **Авторизация**: Вход по телефону и паролю (интеграция с ArtistCRM API)
- **Задачи контактов**: Экран с задачами по категориям — просрочено, сегодня, завтра
- **Мероприятия**: Базовый экран мероприятий (заглушка)
- **Финансы**: Базовый экран финансов (заглушка)
- **Профиль**: Экран профиля с выходом из аккаунта

### Известные ограничения
- Экраны «Мероприятия», «Финансы» — заглушки, без реальных данных
- Push-уведомления не настроены
- Нет поддержки offline-режима
- Глубокие ссылки не реализованы

### Инструкция для тестировщиков
1. Установите APK/AAB из Google Play Internal Testing
2. Войдите используя свои учётные данные ArtistCRM (телефон + пароль)
3. Проверьте экран «Задачи» — должны отображаться задачи из additionalEvents
4. Проверьте корректность отображения просроченных, сегодняшних и завтрашних задач
5. Проверьте выход из аккаунта через экран «Профиль»

### Требования
- Android 8.0+
- Доступ к API ArtistCRM (бэкенд должен быть доступен)
