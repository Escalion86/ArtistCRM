Страница «Важное» — полировка (макет, не код)

Три экрана: общий вид страницы, свайп-действия у задач, блок сообщений и мероприятий. Светлая тема, ширина телефона 300px. Внизу — текущая нижняя панель с активной «Важное».
1. Саммари-лента сверху — цветные чипы «Просрочено 3 · Сегодня 2 · …», тап по чипу скроллит к секции. Сразу видно масштаб без скролла.
2. Секции с цветным ребром — красный = просрочено, янтарь = сегодня, синий = завтра: секцию узнаёшь по цвету, не читая заголовок.
3. Свайп влево по задаче — действия «Готово», «+1 день», «Удалить» (на десктопе — те же действия по кнопке ⋮). Быстрые переносы остаются чипами внутри карточки.
4. Сообщения с аватаром-инициалом — имя, канал, превью текста, бейдж непрочитанных; тап по карточке открывает диалог.
