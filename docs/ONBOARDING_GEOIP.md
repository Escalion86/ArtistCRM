# Автоподстановка города при первом входе

## Поведение

Мастер первичной настройки запрашивает предполагаемый город по IP при открытии, пока пользователь заполняет профиль. На шаге «Тема и время» он видит заполненное редактируемое поле и пояснение о возможной ошибке определения.

- Сохранённый основной город не заменяется; при просмотре кабинета от имени другого пользователя определение не запускается.
- Если пользователь начал вводить город (даже затем стёр его), запоздавший ответ не перезаписывает поле.
- Сохраняется только подтверждённый кнопкой «Далее» город через существующий `POST /api/site`. Вызов определения ничего не записывает в БД.
- Отказ сети, отсутствие города в базе, отсутствие/повреждение базы или задержка более 4 секунд не мешают ручному вводу.
- Часовой пояс по-прежнему определяется браузером отдельно, не по городу или IP.
- Нет запроса GPS, координат в ответе и передачи IP внешнему GeoIP API. IP не логируется этим функционалом. Существующие журналы reverse proxy управляются отдельно.
- IP-геолокация приблизительна: VPN, корпоративная и мобильная сеть могут указывать другой город. Текущее местоположение также может отличаться от основного города работы артиста.

## Включение на сервере

Без локальной базы функция **не включается автоматически**. Файл базы не поставляется с приложением и не скачивается во время сборки или пользовательского запроса.

1. Получить актуальную базу **City** в формате MMDB, совместимую со структурой GeoLite2-City (`city.names.ru`/`city.names.en`). Базы Country/ASN недостаточно. Для MaxMind нужны собственная учётная запись, доступ к загрузке и соблюдение условий поставщика; проверить доступность для своей организации/региона. Регистрацию и принятие лицензии выполняет владелец сервера.
2. Установить распакованный файл вне проекта и `public`, например `/var/lib/artistcrm/geoip/GeoLite2-City.mmdb`. Дать пользователю процесса Next.js право чтения, не открывать файл по HTTP. `*.mmdb` исключены из git.
3. В окружении **серверного процесса**, не в `NEXT_PUBLIC_*`, задать:

```env
GEOIP_CITY_DB_PATH=/var/lib/artistcrm/geoip/GeoLite2-City.mmdb
GEOIP_TRUST_PROXY=true
```

4. Проверить доверенную границу сети: Next.js должен слушать только localhost или быть закрыт firewall от прямого доступа; входящий nginx должен **перезаписывать**, а не дополнять `X-Real-IP` адресом клиента. В `docs/ARTISTCRM_NGINX.conf` уже есть `proxy_set_header X-Real-IP $remote_addr`. Если перед nginx стоит ещё один proxy/CDN, сначала отдельно настроить получение реального IP только от его доверенных адресов. Не брать произвольный первый элемент `X-Forwarded-For`.
5. Перезапустить приложение после настройки окружения. На localhost без proxy функция обычно возвращает `town: null`; нельзя включать доверие к заголовку на общедоступном сервере Next.js без proxy.
6. Организовать обновление базы средствами поставщика с соблюдением его лицензии. Заменять файл атомарно по тому же пути. Приложение перечитывает базу при следующем запросе после часового срока кэша; для немедленного применения перезапустить процесс. Ошибка открытия повторно проверяется не чаще раза в минуту. Ключи скачивания не нужны приложению и не должны попадать в браузер/git.

Имена берутся сначала из `city.names.ru`, затем из `city.names.en`. Если города нет, регион или город часового пояса не подставляется вместо него.

Документация поставщика: [GeoLite — получение и ограничения](https://dev.maxmind.com/geoip/geolite2-free-geolocation-data/), [обновление локальных баз](https://dev.maxmind.com/geoip/updating-databases/), [библиотека чтения MMDB](https://github.com/runk/node-maxmind).

## API и проверка

`GET /api/site/detected-city` проверяет `getTenantContext()`. Не принимает произвольный IP через query/body, не обращается к данным других tenant и не отдаёт IP/координаты/путь к базе.

- `200`: `{ "success": true, "data": { "town": "Красноярск" } }`.
- `200`, если определение выключено или недоступно: `{ "success": true, "data": { "town": null } }`.
- `401`: `{ "success": false, "error": "Не авторизован" }`.
- `503` при непредвиденном сбое: безопасное сообщение без технических деталей.
- Все ответы: `Cache-Control: private, no-store, max-age=0`; клиент также использует `cache: 'no-store'`.

Автоматические регрессии:

```sh
node --test server/cityGeolocation.test.mjs tests/components/onboardingTown.test.cjs helpers/firstRunWizard.test.mjs
```

Production smoke-check после установки базы: новый аккаунт с пустым городом; сохранённый город; ввод до завершения запроса; отказ сети; неизвестный IP; повторное открытие мастера; светлая/тёмная тема на телефоне. Проверить, что без нажатия «Далее» определённый город не записывается в настройки.
